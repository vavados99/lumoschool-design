== слабые места (честно) ==
  1. Радиальная карта: внутренние кольца (Сб/Нд) короче по дуге — выходные визуально «легче» при той же загрузке; на телефоне ячейка ≈13 px, точный тап труден (компенсация: чипы дней + стрелки на клавиатуре).
  2. Подпись-пояснение карты («кольцо = день, сектор = час») на ноутбуке 1440×900 уходит под первый экран; на телефоне под первым экраном легенда и часть чипов дней.
  3. Телефон: страница ≈9600 px высотой, секций без навигации-чипов (nav скрыт ради места); строка «изменения — к прошлому периоду» на телефоне только для скринридера.
  4. Нет цветового кодирования «хорошо/плохо»: падение = стрелка вниз + слово для скринридера (сознательно, из-за одного акцента); может читаться слабее, чем у эталонов.
  5. Данные демонстрационные и не вполне согласованы между периодами (когорты не зависят от периода; курс 1 PLN = 10,40 UAH условный); таблица ролей — чипы, а не матрица.
  6. Проверка контраста — по пикселям вокруг текста (приближение); skip-ссылка вне экрана исключена из замера. Смена языка на телефоне меняет высоту страницы (перенос строк), CLS при этом 0 (это не загрузка, но «дёрганье» ниже экрана возможно).
