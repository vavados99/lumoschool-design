# LUMOSCHOOL — дизайн и документы

Всё, что Хермес наработал для школы LUMOSCHOOL, кроме кода. Код платформы и главная сайта — в отдельном закрытом хранилище `vavados99/lumoschool`.

Снимок на 21.10.2026. Хермес на паузе до 01.11.2026 (см. СЕЙЧАС.md, блок «Флаги»).

## Что где
- `прототипы-люмо/` — прототипы экранов: B-эмоции…B5-тьма (главная), В3-комната, В4-кабинет, В5-родитель, В6-преподаватель, В7-владелец, В8-публичные; замеры и кадры всех кругов правок.
- `визуалы/` — логотип (круги правок), 10 концептов, направления, референсы.
- `база-люмо/` — персонаж Люмо и база со старого сайта.
- `ДОРОГА.md` — дорожная карта (что сделано, что осталось), `СЕЙЧАС.md` — текущее состояние, `ЖУРНАЛ.md` — история решений, `ЗАДАНИЕ.md`, `ПЛАН-ЭТАП-0.md`, `РАСХОДЫ.md`, `РЕФЕРЕНСЫ.md`.
- `tools/` — рабочие скрипты Хермеса (кадры, замеры, счётчик трат, проверка на секреты).
- `.tmp/` — разборы арт-директора (Опуса) по кругам: `opus_*.txt`.

Ключей, баз данных и служебных копий здесь нет — вырезаны и проверены перед отправкой.
