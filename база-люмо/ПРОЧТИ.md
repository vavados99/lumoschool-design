# Стартовый набор Люмо — из старой школы (собран 15.10.2026)

## Решение Влада (15.10.2026, дословно по смыслу)

Главная идея LUMOSCHOOL — **живой персонаж Люмо** со старого сайта школы. Первый экран: https://lumo-school.vercel.app/ru (там он живой, с эмоциями, реагирует на гостя). Персонажа и основной базовый дизайн берём оттуда за основу. **Все остальные блоки сайта переделываем.** Дальше ведёшь ты как продюсер, по уставу.

Это закрывает выбор из 10 картинок-стопок: они больше не нужны как направление. Решение отменяет строку плана этапа 0 «персонаж Люмо выброшен».

## Что берём, а что переделываем

- **Берём:** облик (капля «живого стекла» циан → маджента), живость и эмоции, характер и голос, ощущение первого экрана, где гость может «потрогать» Люмо.
- **Переделываем:** все остальные блоки сайта. Старые цвета интерфейса, сетку и тексты не переносить вслепую: Влад браковал старый дизайн в целом, хвалил именно Люмо.
- **Слабые места старого Люмо** (поправить, а не перенести): тело — плоская картинка, эмоции даёт только поведение, мимики почти нет (улыбка одна); позы из `арт/позы-эмоции/` в код так и не попали. Первая отрисовка была тяжёлой: замер показывал 5,1 с при норме 2,5, тело потом ужали в webp.

## Развилки — вынести Владу в карточке, а не решать молча

1. **Игровой слой.** На старом сайте есть «покормить / уложить спать» и звёзды. В ЗАДАНИИ записано «без игровых механик». Сам персонаж игрой не считается, а звёзды и кормление — это игра. Рекомендация: в трёх вариациях живого прототипа показать разную меру. Например: (а) Люмо — тихий живой проводник без кнопок; (б) Люмо отвечает на касание эмоцией, без валюты и счёта; (в) дерзкий вариант. Влад выберет глазами.
2. **Голос для старших.** Паспорт голоса писался для детей 4–17. Если LUMOSCHOOL шире по возрасту, голос для подростков и взрослых надо писать заново (в старом проекте его нет).
3. **Торговая марка Lumo.** У Proton есть ИИ-ассистент Lumo. Риск уже отмечен в плане этапа 0. До логотипа — проверка регистров.
